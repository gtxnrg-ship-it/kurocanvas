# Project Art Direction and Visual Continuity

Kuro Canvas separates the project's unified creative direction from chronological character appearance records.

## Style mixing without drift

Record each inspiration with a narrow aspect: for example, relationship-comedy timing, linework/rendering, palette, or ensemble dynamics. Turn each into an original craft rule; do not copy signature characters, panels, dialogue, or compositions. The saved project art direction remains the controlling style contract.

## Character visual timeline

Each approved visual state is tied to a story order and may also carry a chapter number. Only approved states are used. For a requested chapter, Kuro should use the latest approved state at or before that chapter; later scars, haircuts, aging, outfits, injuries, and knowledge must not leak into earlier scenes.

## Approval and uncertainty

Proposed inspirations, rules, and character states are not canon. Conflicting approved states at the same story order block generation rather than selecting a random version. If the required state is missing, ask for a reference or state that it is unknown.

## Reference research

The Style Bible offers direct image-search and source-context search links. Users should review sources and record the specific craft aspect being referenced. This is a research aid, not yet an automated image-search or rights-clearance pipeline.

## Current limitations

Prompt constraints reduce style drift but do not guarantee that every connected model obeys them. Before calling the system release-ready, evaluate multi-chapter character sheets, scar persistence, chapter regressions, style consistency across generated panels, and model/provider behavior with a dedicated regression suite.
